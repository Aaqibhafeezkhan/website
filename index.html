Two ways to get a page

Pick the one that fits you. You can switch later.

Instant

No website? We've got you.

Fill in your name, a tagline and your links. We render a fast, beautiful page - light and dark mode, six themes, nothing to host, nothing to pay.

{
  "mode": "instant",
  "owner": { "github": "you" },
  "page": {
    "type": "person",
    "title": "Your Name",
    "tagline": "What you're about",
    "theme": "sunrise"
  }
}
Point

Already hosting somewhere?

Point your name at GitHub Pages, Vercel, Netlify, Cloudflare Pages - anywhere. You keep your site; you get a friendlier address for it.

{
  "mode": "point",
  "owner": { "github": "you" },
  "records": {
    "CNAME": "you.github.io"
  }
}

How claiming works

About a minute, start to finish.

1. Write your page file

Our guided form writes the JSON for you - no hand-editing needed.

2. Open a pull request

The form drops you into GitHub with everything prefilled. A friendly checker reviews it in seconds.

3. You've got a page

A maintainer merges, and your page goes live. Share it everywhere - badges included.
